## Run it
Requires Node 20.12+ and a Moth API key from https://platform.mothquantum.com.

```sh
cp .env.example .env   # add your MOTH_API_KEY
npm install
npm start
```

Outputs are written to `output/`, each with a `.provenance.json` recording the engine, params and job ID.
